# Изменения

## 0.9.0

- Автоматическая подготовка подключения: проверка сохранённого метода по публичным узлам, подбор при необходимости и отдельный подбор Discord. Методы уже работающего фильтра сами не переключаются.
- Подключение при открытии — отдельное согласие пользователя; старым настройкам эта опция автоматически не добавляется. Подтверждение Windows сохраняется.
- Установка компонентов одним подтверждением, проверка SHA256 и повторное использование установленного. В автоматическом режиме runtime Telegram нужен только выбранному установленному клиенту.
- Пять разделов настроек: «Основное», «Приложения», «Профили», «Обновления», «Дополнительно». Выбор приложений виден сразу; технические параметры отделены.
- Импорт/экспорт пресета одним JSON-файлом и возврат рабочей конфигурации. Перед импортом/восстановлением текущие настройки сохраняются отдельно; импорт не включает автоподключение.
- Кеш методов по хешам сети и настроек: до 128 записей/128 КиБ, срок 7 дней, повторная проверка перед использованием.
- Автоматический запуск Telegram-модуля в трее и однократное предложение штатного `tg://proxy`. Подтверждение остаётся в Telegram; его файлы аккаунта не читаются и не меняются.
- Проверка обновлений приложения на GitHub раз в сутки; выбор «Обновить», «Позже» и «Не напоминать» об этой версии, отдельное отключение автоматики и ручная проверка.
- Обязательная проверка подписанного RSA-4096-манифеста с закреплённым публичным ключом, SHA256 архива, сохранение предыдущей версии и откат при неудачном запуске. Приватный ключ не распространяется.
- Привязка сохранённого пресета к сети Windows; при смене сети появляется предложение, без автоматического переключения.
- Мастер «Что не работает?» с десятью сценариями и отдельным файловым отчётом.
- Восстановление прежнего метода после сбоя или сна: до трёх попыток через 5/15/45 секунд; ручная остановка отменяет повторы.
- Повышенное окно передаёт установку/откат неповышенному помощнику через доверенный Explorer. Готовность помощника подтверждается до остановки приложения; отмена отзывает передачу, временные блокировки файлов обрабатываются ограниченными повторами.

## 0.8.5 — 28.10.2026

- Убраны дублирующая стрелка возврата и повторный переключатель публичного списка.
- Общий кэш компонентов с проверкой контрольных сумм и переносом подходящих старых файлов без скачивания.
- Обновление Telegram-модуля не перезаписывает EXE работающей старой версии.
- Добавлена веб-категория DCS; игровые категории явно подписаны как веб.
- Исправлен общий лимит встроенных и пользовательских доменов: 128 вместо 32.
- Обновлены описание приложения и документация; старые архивы и повторяющиеся release-инструкции убраны из основной ветки.

- Именованные пресеты с восстановлением выбранной настройки при запуске.
- Игнорирование признаков VPN на один запуск автоподбора.

## 0.8.2 — 27.10.2026

- Вернулась автоматическая установка компонентов из приложения: один запрос, загрузка и подготовка без PowerShell.
- Зависимости Telegram устанавливаются тем же способом.
- В Windows-архиве остались только приложение, его конфигурация и лицензии. Исходники, тесты и инструменты сборки — в отдельном архиве.
- Сокращены описание GitHub и инструкция запуска.

## 0.8.1 — 26.10.2026

- Рядом с кнопкой «Баг-репорт» добавлена ссылка @AresC404 для связи в Telegram. Архив прикрепляется пользователем вручную; автоматической отправки нет.
- Контакты GitHub и Telegram добавлены в документацию проекта.
- Уточнена подготовка публичного Windows-выпуска: сетевой движок и необязательный Python-runtime не входят в архив программы.

## 0.8.0 — 25.10.2026

- Кнопка «Баг-репорт» на главном экране сохраняет один ZIP для ручной отправки. Работает без отключения фильтра и без запуска новых сетевых проверок.
- Добавлена ограниченная локальная история событий между запусками: операции, категории ошибок, результаты проверок и состояния приложения.
- Отчёт включает безопасный снимок настроек и последнего профиля движка, версии компонентов, хронологию и контрольные суммы содержимого архива.
- В отчёт не копируются исходный журнал окна, сообщения исключений, пользовательские домены, VPN-адреса, ключи и файлы учётных записей. Автоматической отправки нет.
- История начинается с этой версии; ограничения объёма и пропущенные записи видны в отчёте.

## 0.7.0 — 25.10.2026

- Один главный экран: включение, выключение и результаты проверки. Боковое меню и отдельная страница проверок убраны.
- Шестерёнка справа сверху открывает полноэкранную страницу настроек без сброса результатов и ввода. Стрелка «Назад» или Esc возвращает к подключению.
- Выбор сервисов, расширенный список доменов, протоколы и журнал перенесены в дополнительные настройки. На главном экране нет их карточек, счётчиков и пояснений.
- Автоподбор запускается из настроек и возвращает на главный экран, где видны ход операции и отмена.
- В тёмной теме убраны белая заливка основной кнопки и видимость отключённых нативных контролов за настройками.
- Полосы прокрутки настроек, полей и результатов в тёмной теме больше не имеют белой заливки. Нативное управление прокруткой и системная высокая контрастность сохранены.
- Сетевые методы, формат настроек, трей и свободное использование без активации сохранены.
