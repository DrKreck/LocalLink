# LocalLink

Приложение для Windows: профили обхода DPI-блокировок, автоподбор и диагностика подключения.

## Запуск

Windows 10/11 x64.

1. Распакуйте архив и откройте **LocalLink.exe**.
2. Подтвердите загрузку компонентов — приложение само скачает и установит всё нужное.
3. Нажмите **Включить**.

## Возможности

- Проверка подключения и подбор метода.
- Профили Discord, YouTube, Telegram и других сервисов.
- Категории и поиск доменов, исключения и сохранение пресетов.
- Темы, трей и автозапуск.
- Баг-репорт одним ZIP: сохраните его и отправьте [@AresC404](https://t.me/AresC404) или на [kirill0063@gmail.com](mailto:kirill0063@gmail.com).
