# LocalLink

Графический интерфейс **zapret2** для Windows.

**[Скачать для Windows](https://github.com/DrKreck/LocalLink/releases/download/v0.8.3/LocalLink-0.8.3-windows-x64.zip)** · [Исходники](https://github.com/DrKreck/LocalLink/releases/download/v0.8.3/LocalLink-0.8.3-source.zip) · [Telegram](https://t.me/AresC404) · [Boosty](https://boosty.to/aresc404)

![Интерфейс LocalLink](docs/images/interface.png)

## Запуск

Windows 10/11 x64.

1. Распакуйте архив и откройте **LocalLink.exe**.
2. Подтвердите загрузку компонентов — приложение само скачает и установит всё нужное.
3. Нажмите **Включить**.

## Возможности

- Проверка подключения и подбор метода.
- Настройки Discord, Telegram и других сервисов.
- Темы, трей и автозапуск.
- Баг-репорт одним ZIP: сохраните его и отправьте [@AresC404](https://t.me/AresC404).
