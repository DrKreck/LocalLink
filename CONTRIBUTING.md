## Изменения кода

Используйте C# 5 / .NET Framework 4.8 x64 и существующие средства сборки. Не добавляйте зависимости без необходимости. Проверяйте входные данные и сохраняйте ограничения размеров, отмену операций и корректную остановку собственных процессов.

Для сборки из исходников нужны Windows x64 и .NET Framework 4.8. Из корня исходников:

```powershell
.\tools\Setup-Engine.ps1
.\Build.ps1 -OutputDirectory .\artifacts\review
.\diagnostics\Test-UI.ps1 -BuildDirectory .\artifacts\review
```

`Setup-Engine.ps1` подготавливает файлы для сборки; обычным пользователям он не нужен. Уже подготовленный движок можно передать параметром `-EngineDirectory` команды `Build.ps1`. Добавляйте регрессионный тест к исправлению.

Сборка и офлайн-тесты не запускают драйвер и не меняют сетевые настройки. Живые сетевые проверки выполняются отдельно.

## Подготовка runtime разработчиком

Обычные пользователи устанавливают компоненты из приложения. Для пересборки runtime используется `tools/Build-TelegramRuntime.ps1 -SourceDirectory <подготовленный CPython> -OutputDirectory <новая папка>`. Закреплённые версии: CPython 3.12.14, cryptography 50.0.1, cffi 2.1.1, pycparser 3.0. Готовую папку можно передать `Build.ps1 -TelegramRuntimeDirectory <папка>`; существующий runtime не перезаписывается. Закреплённые файлы и лицензии сохраняются.

Сохраняйте лицензии и атрибуцию сторонних компонентов. Вклад в авторский код проекта принимается на условиях MIT.
