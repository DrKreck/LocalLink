# LocalLink 0.9.0

Крупное обновление: автоматическая настройка подключения, новые разделы настроек и подписанные обновления приложения.

- Автоматическая настройка: проверка сохранённого метода и подбор при необходимости. Для Discord — отдельный подбор без смены общего метода остальных сервисов.
- Компоненты устанавливаются после одного подтверждения; уже подходящие файлы проверяются и используются повторно.
- Настройки разделены на «Основное», «Приложения», «Профили», «Обновления» и «Дополнительно». Ручные методы, VPN-параметры и журнал не мешают основному сценарию.
- Пресеты можно передавать одним JSON-файлом. «Запомнить рабочие» и «Вернуть рабочие» позволяют восстановить проверенную конфигурацию; текущая сохраняется перед заменой.
- Рабочие методы запоминаются для сети и проверяются при следующем подключении. Во время уже работающего фильтра автоматического перебора методов нет.
- Telegram-модуль может запускаться в трее автоматически. Первое предложение локального прокси подтверждается в самом Telegram; файлы аккаунта не изменяются.
- Обновления приложения: «Обновить», «Позже» и «Не напоминать», обязательная RSA-4096-подпись, сохранение настроек и откат.
- Автоподключение ждёт завершения установки новой версии, чтобы запрос прав Windows не вызвал ошибочный откат.
- Мастер «Что не работает?» создаёт целевой ZIP-отчёт. Восстановление после сбоя/сна повторяет прежний профиль до трёх раз; ручная остановка отменяет повторы.

## Автоматическое подключение

Автоматическая настройка включена по умолчанию и работает при подключении. Запуск подключения при открытии LocalLink — отдельная опция: прежним пользователям она сама не включается. Необходимые права запрашиваются обычным окном Windows.

В автоматическом режиме дополнительные компоненты Telegram подготавливаются для выбранного установленного клиента. Ручная кнопка модуля доступна в «Приложениях». Остановка основного фильтра не завершает отдельный Telegram-модуль; им можно управлять через его значок в трее.

Импорт пресета не включает подключение при запуске, не переносит привязки сетей и не меняет напоминания об обновлениях.

Автоматика оценивает публичные узлы сервисов. Эти пробы не подтверждают голос, работу аккаунта или подключение к игровому серверу.

## Обновления и отчёты

Обновление скачивается со стабильного релиза `DrKreck/LocalLink` только после согласия. «Позже» откладывает предложение на сутки, «Не напоминать» пропускает эту версию. Автопроверки можно отключить, сохранив ручную кнопку. Если загрузка или проверка подписи не удалась, остаётся текущая версия.

Откат сохраняет текущие настройки. Резервная версия и журнал установки находятся в `%LOCALAPPDATA%\LocalLink\updates`.

Баг-репорты сохраняются пользователем в файл, без автоматической отправки. Подробности хранения данных — в [PRIVACY.md](PRIVACY.md), сопровождения подписи — в [UPDATE-SIGNING.md](UPDATE-SIGNING.md).
