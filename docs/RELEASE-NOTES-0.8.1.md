# LocalLink 0.8.1

Графический интерфейс zapret2 для Windows. Бесплатно, без регистрации и ключей доступа.

- Включение и проверка подключения в одном окне.
- Подбор метода и отдельные настройки Discord.
- Светлая/тёмная темы, трей и автозапуск.
- Файловые баг-репорты и контакт @AresC404 рядом с кнопкой отчёта.

## Установка

Windows 10/11 x64, .NET Framework 4.8.

1. Распакуйте `LocalLink-0.8.1-windows-x64.zip` целиком.
2. В PowerShell из папки программы выполните `.\tools\Setup-Engine.ps1`.
3. Запустите `LocalLink.exe` и нажмите **Включить**.

Движок скачивается отдельно с проверкой хешей. Python-runtime для необязательного моста Telegram в архив не включён; инструкция — в `telegram_bridge/README.md`.

LocalLink не является VPN и не гарантирует работу во всех сетях. Голос, видео и игры проверяйте в приложениях.

При ошибке сохраните ZIP кнопкой **Баг-репорт** и отправьте его приватно в [Telegram @AresC404](https://t.me/AresC404). Не прикладывайте отчёт к публичному issue.

[Поддержать на Boosty](https://boosty.to/aresc404) — добровольно, без платных функций. Код LocalLink — MIT; лицензии зависимостей перечислены в `THIRD-PARTY.md`.
