## Проверка

Сборка и проверки выполнены в рабочем каталоге и повторены из отдельного публичного исходного пакета. Новый сетевой фильтр не включался; ссылка Telegram в реальном браузере не открывалась.

```powershell
.\Build.ps1 -OutputDirectory <папка сборки> -EngineDirectory <подготовленный движок> -TelegramRuntimeDirectory <подготовленный runtime>
.\diagnostics\Test-UI.ps1 -BuildDirectory <папка сборки>
.\Export-OpenSource.ps1 -OutputDirectory <новая папка исходников>
.\Package-Release.ps1 -BuildDirectory <папка сборки> -OutputDirectory <новая папка выпуска>
```

## Состав и ограничения

Публичный Windows-архив не содержит стороннего сетевого движка или Python-runtime. Перед включением фильтра пользователь запускает `tools\Setup-Engine.ps1`; скрипт получает закреплённые компоненты с проверкой хешей. Мост Telegram — необязательный отдельный компонент. Лицензии перечислены в [THIRD-PARTY.md](../THIRD-PARTY.md).

LocalLink не является VPN, не меняет внешний IP и не гарантирует доступность всех сервисов. Состояние процесса фильтра и ответы веб-узлов не подтверждают работу голоса, видео, сообщений или игр.

Файловый отчёт содержит ограниченную историю LocalLink, а не полный журнал компьютера. Старые несохранённые события и внутренние журналы сторонних приложений не восстанавливаются. Подробности: [PRIVACY.md](PRIVACY.md).

## Обновление и откат

Завершите прежнюю версию через «Выход» в трее и запустите новый выпуск из отдельной папки. Старые каталоги сохраняются. Для отката завершите новый выпуск и вернитесь к прежнему; путь автозапуска меняется только явной кнопкой пользователя.
