# Telegram

Отдельный локальный мост для Telegram Desktop. Звонки не поддерживаются.

1. В настройках LocalLink нажмите «Открыть модуль Telegram». Компоненты приложение подготовит само.
2. Дождитесь «Готов» и нажмите «Подключить Telegram».
3. Подтвердите прокси в Telegram.

Окно закрывается в трей. Для выхода используйте «Остановить». Перед выходом отключите этот прокси в Telegram, иначе клиент продолжит подключаться к остановленному модулю.

## Компоненты

Системный Python не нужен. Изолированный runtime устанавливается из приложения, проверяется по закреплённым SHA-256 и переиспользуется при обновлениях. Каждый launcher имеет отдельное имя по хешу: старый работающий модуль не перезаписывается.

Сборка runtime для разработчиков описана в [CONTRIBUTING.md](../CONTRIBUTING.md).

## Работа

Модуль слушает `127.0.0.1:1443`. Локальный секрет прокси защищён DPAPI текущего пользователя и хранится в `proxy-secret.dpapi`. Это не ключ аккаунта Telegram; не публикуйте этот файл.

Мост преобразует внешнюю обфускацию MTProxy в MTProto через TLS/WebSocket к узлам Telegram. Проверка сертификатов включена; внутреннее шифрование MTProto не снимается. Данные аккаунта и переписка не читаются. Исходящие соединения привязываются к одному физическому IPv4-адаптеру, а при изменении сети модуль пытается восстановить собственные соединения.

DNS, маршруты, системный прокси и брандмауэр не меняются. Модуль работает отдельно от главного окна LocalLink. Наличие WSS-соединения ещё не означает, что сообщения и медиа доступны: это проверяется в самом Telegram.

Ограничения: до 8 соединений, кадры до 1 MiB, экспериментальные направления DC2/DC4. Доступность зависит от сети и узлов Telegram.
